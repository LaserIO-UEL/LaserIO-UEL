# Fluid Card

Fluid Cards are used to send Fluids between inventories, such as tanks.

mb/t values (max) for Overclockers:


- 0 Overclockers: 5,000mb/20t
- 1 Overclocker: 10,000mb/16t
- 2 Overclockers: 20,000mb/12t
- 3 Overclockers: 30,000mb/8t
- 4 Overclockers: 40,000mb/4t

NOTE: These values are the default and can be changed by config.
