# レーザー中継器

複数の[レーザーノード](./laser_node.md)は、[レーザーレンチ](../tools/laser_wrench.md)を使用して直接相互に接続できますが、最大範囲は8ブロックです。

レーザー中継器は、ノード間のより安価な中間ポイントとして機能し、相互接続されたインベントリのネットワークを構築できます。
