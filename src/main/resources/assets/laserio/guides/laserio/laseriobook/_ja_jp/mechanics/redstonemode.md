# レッドストーンモード

レッドストーンモードは、[レッドストーンチャンネル](./redstonechannel.md)のレッドストーン信号がカードにどのように影響するかを決定します。

デフォルトでは、これは**無視**に設定されており、カードは常に動作し、レッドストーンは影響しません。



低に設定すると、カードはレッドストーンチャンネルにレッドストーン信号がない場合にのみ機能します (チャンネルボタンはレッドストーン切り替えの右側にあります)。

レッドストーン高モードでは、カードはレッドストーンチャンネルにレッドストーン信号がある場合にのみ機能します。
