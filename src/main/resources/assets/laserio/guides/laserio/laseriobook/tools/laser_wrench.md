# Laser Wrench

The Laser Wrench is primarily used to connect multiple Blocks together.

[Nodes](../blocks/laser_node.md) and [Connectors](../blocks/laser_connector.md) can be connected by Shift-RightClicking to select a block, and then right clicking another block to form a connecion.

The max connection range is 8 blocks.

## Laser Wrench

*The currently selected block is highlighted green.*

![](laser_wrench.png)

Linking Nodes one by one after you placed them can be tedious; luckily the Laser Wrench can automatically do that for you!

While placing Nodes, holding the Laser Wrench in your offhand automatically connects each node to the previously placed one!

Note: this feature works with (Advanced) Laser Connectors as well!
