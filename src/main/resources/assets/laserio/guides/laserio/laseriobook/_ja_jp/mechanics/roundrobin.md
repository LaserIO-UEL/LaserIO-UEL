# ラウンドロビン

ラウンドロビンは搬出モードでのみ使用できます。

ラウンドロビンは、搬出カードにアイテムを複数の挿入カードに均等に分配するように指示します。

3つのモードがあります:
1. 無効
2. 有効
3. 強制

**無効** に設定すると、ラウンドロビンは無効になり、[優先度](./priority.md)システムが適用されます。最初のインベントリが完全にいっぱいになってから、オブジェクトが2番目のインベントリに送られます。

**有効**に設定すると、アイテムは優先順位に従ってチェストに送られ、均等に分配されます。

ネットワークに3つのチェストがある場合、最初のアイテムセットは最初のチェストに、2番目のセットは2番目のチェストに送られます。

**強制** に設定すると、「有効」と同じルールが適用されます。ただし、宛先の1つがいっぱいになると、搬出機能は、その宛先が再び使用可能になるまで動作を停止します。

注: チャンクのアンロードにより、特に一部のノードがアンロードされ、他のノードがアンロードされない場合、ラウンドロビンの仕組みが変更される可能性があります。
