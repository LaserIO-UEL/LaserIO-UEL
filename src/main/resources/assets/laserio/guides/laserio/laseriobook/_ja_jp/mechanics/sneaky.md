# スニーキー

スニーキー設定は、カードが隣接するインベントリのどちら側で操作を試みるかを決定します。

たとえば、かまどはブロックの「上側」からアイテムを受け入れます。ノードがかまどの側面にある場合は、搬入カードの スニーキーモードを「上」に設定します。

このカードは、かまどの「上」側にアイテムを搬入しようとします。

別のカードを「スニーキー下」に設定して、かまどの底に燃料を搬入することができます。
