# ロジスティックオーバークロッカー

ロジスティックオーバークロッカーを使用すると、個々のカード(エネルギーカードを除く)の動作が速くなります。

たとえば、アイテムカードは20ティック(1秒)ごとに最大8つのアイテムしか抽出できません。4つのオーバークロッカーをインストールすると、4ティックごとに64個のアイテムを抽出できます。

各カードがオーバークロッカーによってどのように影響を受けるかについては、カードの項目を参照してください。
