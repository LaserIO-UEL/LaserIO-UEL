# タグフィルター

タグフィルターを使用すると、プレイヤーはリソースのタグでフィルターできます。

タグは、Minecraft で類似のリソースをグループ化する方法です。たとえば、右側では、鉄のインゴットに「forge:ingots」タグが付いていることがわかります。金、銅、錫などにも同様のタグが付いています。

タグフィルターを使用すると、1つのエントリですべてのインゴットを並べ替えることができます。

## タグUI

タグUI
![](filter_tag.png)

まず、右上のスロットにアイテムを配置します。このアイテムのタグのリストが <Color id="blue">**青色**</Color> で表示されます。追加したいタグをクリックし、+ボタンを押します。Shiftキーを押しながら+ボタンを押すと、すべてのタグがリストに追加されます。

リストからタグを削除するには、タグを選択して-ボタンを押します。

または、Shift キーを押しながらクリックすると、タグが自動的に追加/削除されます。

X ボタンはリスト全体をクリアします。

リストは「Or」リストとして扱われます。つまり、リストのいずれかのタグに一致するアイテムがフィルターされます。

 タグフィルターはNBT比較をサポートしていません。意味がありません。
