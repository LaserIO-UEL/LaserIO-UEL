# レッドストーンチャンネル

カードには、メインチャンネルとは別に「レッドストーンチャンネル」があります。

これは、カードに影響を与えるレッドストーン信号のチャンネルです。詳細については、[レッドストーンモード](./redstonemode.md) および [レッドストーンカード](./card_redstone.md) の項目を参照してください。
