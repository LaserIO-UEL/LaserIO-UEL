# ネットワーク設定

ネットワーク設定画面は、どの [レーザーノード](../blocks/laser_node.md)画面からでも利用できます。この設定画面では、ネットワークの色を変更できます。この色は、次のものに影響します:
- レーザーノードブロック(ワールド内)
- レーザー中継器ブロック(ワールド内)
- ブロック間のレーザーの色。

## カラフルなノード

*異なる色のネットワーク*

![](images/settings1.png)

ノードとインベントリ(チェストやタンクなど)間のレーザーの色は影響を受けません。

ネットワーク上のノードに変更を加えると、同じネットワーク上の他のすべてのノードに自動的に反映されます。このようにして、世界中に異なる色のネットワークを持つことができます。

これは純粋に装飾的なものであり、機能に実質的な影響はありません。

ノードまたはネットワークを別のネットワークに追加する場合は、次のルールが適用されます:

ノード/ネットワークの 1 つに色設定があり、もう一方がデフォルトである場合、デフォルトが常に上書きされます。

それ以外の場合、強調表示されたブロックは、クリックして接続すると、その設定を送信します。たとえば、緑のノードをShiftキーを押しながらクリックしてから、青のノードをクリックすると、青のノードが緑に変わります。

アルファには、アルファとレンチアルファの2つの設定があります。

アルファは、2つのブロック間を移動するレーザーにのみ影響し、そのレーザーの透明度を決定します。0に設定すると、ノード/コネクタ間のレーザーはまったく見えなくなります。

レンチアルファは、プレイヤーがレンチを持っているときに、この設定をアルファに追加します。

たとえば、アルファを0に設定し、レンチのアルファを80に設定すると、レンチを持っているときにのみレーザーが表示されます。

アルファを80に設定し、レンチのアルファを200に設定すると、レンチを持っているときにレーザーがより明るく表示されます。2 つの数値を加算したときに255を超えても問題はありません。自動的に255に制限されます。
