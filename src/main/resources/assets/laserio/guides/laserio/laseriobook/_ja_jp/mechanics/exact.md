# 正確

正確モードは、搬出モードとストックモードでのみ使用できます。

正確モードでは、「搬出量」フィールドで設定された正確な量のアイテムが搬出されます。例えば、搬出量が8に設定されていて、隣接するチェストにアイテムが5個しかない場合、搬出カードは8個になるまでアイテムを搬出しません。

ストックモードカードの場合、正確モードの動作は若干異なります。正確モードでは、在庫要求を満たすために必要な量または搬出量のうち、どちらか小さい方の量がネットワークで利用可能な場合にのみ、アイテムの移動が許可されます。

例えば、ストッカーにさらに13個のアイテムが必要で、一度に32個を搬出できる場合、ネットワークのどこかに13個のアイテムがある場合にのみ搬出が行われます。
